In reStructuredText (.rst) files, you can use various formatting options to structure and style your documents. 
Here are some common formatting options:

1. **Headings**:
    ```restructuredtext
    Heading Level 1
    ===============

    Heading Level 2
    ---------------

    Heading Level 3
    ~~~~~~~~~~~~~~~
    ```

2. **Bold and Italics**:
    ```restructuredtext
    **bold text**
    *italic text*
    ```

3. **Lists**:
    - **Bullet Lists**:
      ```restructuredtext
      - Item 1
      - Item 2
      - Item 3
      ```

    - **Numbered Lists**:
      ```restructuredtext
      1. First item
      2. Second item
      3. Third item
      ```

4. **Links**:
    ```restructuredtext
    `Link text <http://example.com>`_
    ```

5. **Code Blocks**:
    ```restructuredtext
    .. code-block:: python

        def hello_world():
             print("Hello, world!")
    ```

6. **Inline Code**:
    ```restructuredtext
    ``inline code``
    ```

7. **Block Quotes**:
    ```restructuredtext
    > This is a block quote.
    ```

8. **Tables**:
    ```restructuredtext
    +------------+------------+
    | Header 1   | Header 2   |
    +============+============+
    | Cell 1     | Cell 2     |
    +------------+------------+
    ```

These are just a few examples of the formatting options available in reStructuredText. You can combine these elements to create well-structured and readable documents.
